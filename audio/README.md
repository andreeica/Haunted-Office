# 🎵 Аудио файлы для Haunted Office

Поместите следующие аудио файлы в эту папку:

## Основная тема (фоновая музыка при загрузке):
- `prologue.mp3` или `prologue.wav` - John Williams Prologue (Star Wars)

## Backend Team (Star Wars Dark Side):
- `imperial-march.mp3` - Imperial March Theme
- `darth-vader.mp3` - Darth Vader Theme (для лидера)
- `starwars-background.mp3` - общий Star Wars фон

## Frontend Team (Фиксики):
- `fixiki-theme.mp3` - Кто такие фиксики (тема из мультика)
- `fixiki-background.mp3` - фоновая музыка Фиксиков

## QA Team (Matrix):
- `matrix-theme.mp3` - Matrix Theme
- `matrix-background.mp3` - Matrix background sounds

## BA/Support Team (Mystics):
- `mystics-theme.mp3` - мистическая тематика
- `mystics-background.mp3` - мистический фон

## DevOps Team (Infrastructure):
- `infra-theme.mp3` - техно/электро тема
- `infra-background.mp3` - инфраструктурный фон

## Скачать музыку:
- Star Wars: https://www.youtube.com/results?search_query=star+wars+imperial+march
- Фиксики: https://www.youtube.com/results?search_query=фиксики+тема
- Matrix: https://www.youtube.com/results?search_query=matrix+theme
- Halloween: https://www.youtube.com/results?search_query=halloween+ambient

**Используйте YouTube to MP3 конвертеры или загрузите готовые файлы.**

## Альтернативный вариант:
В `teams.html` и `index.html` можно изменить ссылки на онлайн версии музыки через `<audio>` теги.
